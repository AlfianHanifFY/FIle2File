# EXECUTIVE SLIDE DESIGN SYSTEM & TOKENS

## 1. Primary Layout Types

- Type A (Analytical Slidocument): 16:9 widescreen, 5-card KPI ribbon, 3 vertical bento containers, persistent bottom chevron progress bar, 8pt footnote gutter.
- Type B (Strategic Journey / Roadmap): S-curved winding 3D ribbon path, 5-6 milestone check-in nodes, date pills, dark blue summary bento box on top left, trophy/grand outcome container bottom right.

## 2. Color Hex Codes

- Background: #F8FAFC (Soft off-white / gray-blue)
- Dark Containers & Headers: #00205B / #0B2545 (Deep Corporate Navy)
- Primary Accent: #1D4ED8 (Royal Blue)
- Highlight Badges: #0284C7 (Cyan/Electric Blue)
- Text Primary: #0F172A (Slate Black)
- Text Muted/Footnotes: #64748B (Slate Gray)

## 3. Negative Constraints (Strict Zero-Tolerance)

- No cartoon characters, no hand-drawn doodles, no childish illustrations, no empty airy whitespace.
